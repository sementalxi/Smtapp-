SEMENTAL MULTI-CHANNEL RULES BOT — UPLOAD READY

1. Upload ALL files in this folder to the ROOT of your GitHub repository.
   package.json must be visible at the repository root.

2. Railway Variables:
   DISCORD_TOKEN = token from Discord Developer Portal > Bot
   CLIENT_ID = Application ID from the SAME Discord application
   GUILD_ID = your Discord server ID
   RULES_DATA_DIR = /data

3. Railway Start Command:
   npm start

4. Recommended persistent storage:
   Create a Railway Volume mounted at /data.

5. Redeploy.

Expected logs:
   Registered multi-channel rules commands.
   Logged in as <your bot>

Commands:
   /rules
   /rules-create
   /rules-edit
   /rules-publish
   /rules-list
   /rules-delete

IMPORTANT:
DISCORD_TOKEN and CLIENT_ID must belong to the SAME Discord application.
Never upload a real .env file or bot token to GitHub.
